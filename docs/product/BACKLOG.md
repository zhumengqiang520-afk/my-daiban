# 产品 Backlog 与首版拆分

优先级定义：P0 阻挡上线；P1 首版重要；P2 增强；P3 未来考虑。

## EPIC-00 项目与开源基座

- P0 固定 Vikunja 稳定版本、提交 SHA 和许可证清单。
- P0 建立企业 fork、`origin`/`upstream` 远端及分支保护。
- P0 建立本地开发、单元测试、前端构建和容器构建流程。
- P0 增加中文项目名称、品牌配置和 AGPL 源码入口。
- P1 建立上游同步检查和变更日志。

## EPIC-01 组织、人员和权限

- P0 公司、区域、门店、仓库组织模型。
- P0 成员岗位、归属、直属负责人、账号状态。
- P0 作用域角色和默认拒绝权限校验。
- P0 店长只能访问本店任务和成员的自动化测试。
- P1 临时借调及有效期。
- P1 批量导入组织和成员。
- P2 OIDC/企业微信登录。

## EPIC-02 任务领域扩展

- P0 门店、类别、主负责人、复核人、预计工时和来源字段。
- P0 零售任务状态机及变更日志。
- P0 验收清单和必需凭证规则。
- P1 外部单号、严重程度和任务依赖。
- P1 批量修改负责人和日期。

## EPIC-03 模板和重复派发

- P0 创建、编辑、停用模板。
- P0 每日/每周/每月重复规则。
- P0 按区域和门店批量派发及预览。
- P0 模板版本快照和幂等生成。
- P1 节假日跳过与补发策略。
- P2 模板库导入导出。

## EPIC-04 员工执行端

- P0 移动端“我的今日待办”。
- P0 开始、清单勾选、拍照/上传、提交完成。
- P0 离线或弱网失败时保留表单并允许重试。
- P1 快速筛选和关键字搜索。
- P2 PWA 安装和推送通知。

## EPIC-05 复核和返工

- P0 店长待复核队列。
- P0 通过、驳回、原因和多次提交历史。
- P0 必填凭证和权限校验。
- P1 总部抽检和批量复核。
- P2 随机抽检规则。

## EPIC-06 人员负荷

- P0 默认每日容量和已分配分钟数。
- P0 未来七天人员负荷板。
- P0 超过阈值警告。
- P1 请假、非工作日和临时容量调整。
- P1 拖动改派。
- P2 基于岗位、负荷和门店的候选人建议。
- P3 完整班次排班。

## EPIC-07 提醒与升级

- P0 站内到期前、到期和逾期通知。
- P0 分级升级到店长和区域经理。
- P0 通知幂等、重试和发送记录。
- P1 邮件通知。
- P1 企业微信群机器人通知。
- P2 企业微信应用私聊和回执。

## EPIC-08 看板、报表和审计

- P0 今日总览和逾期清单。
- P0 按门店、类别、人员和日期筛选。
- P0 完成率、按时率、驳回率口径。
- P0 业务提交/复核历史和授权范围检查。
- P0 评估并采购通用审计所需的 Vikunja 许可证，或触发基座重评估。
- P1 CSV 异步导出。
- P1 趋势、人员负荷和门店比较。
- P2 自定义报表。

## EPIC-09 上线保障

- P0 测试、预发布和生产环境。
- P0 自动备份、恢复脚本和恢复演练。
- P0 HTTPS、密钥管理、日志和基础告警。
- P0 用户导入、模板初始化和培训材料。
- P0 回滚预案和上线观察清单。

## 建议首批模板

1. 每日开店检查。
2. 每日闭店检查。
3. 样床和价签检查。
4. 每周库存抽盘。
5. 促销陈列执行。
6. 意向顾客 24 小时回访。
7. 配送异常处理。
8. 售后投诉闭环。
