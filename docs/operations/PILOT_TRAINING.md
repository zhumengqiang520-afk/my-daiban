# 试点培训和一页操作说明

## 店员：每天只记住四步

1. 打开“零售任务 → 执行与复核”，在“我的待办”打开任务。
2. 点“开始执行”，按现场结果逐项勾选验收清单。
3. 需要照片时打开任务详情上传，再回到任务填写完成说明。
4. 点“提交完成”。如被驳回，按原因修正后重新提交。

不要在任务标题、说明或照片中放入顾客完整手机号、身份证、银行卡或家庭地址。配送和售后只填内部订单号。

## 店长：班前、班中、班后

- 班前：查看未来 7 天负荷，调整当日容量，避免单人超载。
- 班中：关注超期队列和站内通知，需要时在 Vikunja 任务详情调整截止时间或协作人。
- 班后：处理“待我复核”，以清单和凭证为准；驳回时写明可执行的修正要求。

## 运营人员：标准化和看指标

- 模板名称说明业务目的，任务标题让店员一眼看懂。
- 清单每行只写一个可验证动作，不使用“处理好”等模糊用语。
- 先手动派发验证，再设置日/周/月自动计划。
- 看板数据用于发现流程和资源问题，不直接作为员工处罚依据。

## 60 分钟试点培训建议

- 0—10 分钟：为什么使用系统、角色与数据范围。
- 10—25 分钟：店员完成一个带照片的开店任务。
- 25—40 分钟：店长驳回、重提和通过。
- 40—50 分钟：人员容量、超载和超期升级。
- 50—60 分钟：学员实操、常见问题和支持入口。
